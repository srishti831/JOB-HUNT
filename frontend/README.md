# JobPortal – frontend

React 19 + Vite + Tailwind v4 + shadcn (base-ui) + Redux Toolkit. See the [root README](../README.md) for setup, deployment and the feature list.

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:8000
npm install
npm run dev            # http://localhost:5173
```
